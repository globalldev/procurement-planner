# Сценарий «что если»

1. Скопируй `config.toml` во временный файл (scratchpad), измени только запрошенный параметр.
2. Посчитай базу и сценарий без перезаписи боевых результатов:
   ```
   python -c "import json,sys;from pathlib import Path;from planner import data,engine;from planner.cli import load_cfg;cfg=load_cfg(Path(sys.argv[1]));ds=data.load(Path('data/raw'),cfg['data']['asof']);print(json.dumps(engine.run(ds,cfg)['kpi']))" <путь_к_config>
   ```
   (для базы — путь к `config.toml`, для сценария — к временной копии).
3. Сравни KPI: штук к заказу сейчас, число SKU в дефиците и потери, избыток, пересмотр цены. Дай таблицу «было → стало» и вывод одной фразой.
4. Если пользователь решает принять сценарий — меняй `config.toml` с комментарием, почему, и запускай `/procurement-run`.
