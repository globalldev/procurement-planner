# Разбор рекомендации по SKU

1. `python -m planner sku <SKU-ID>` — полный расчёт по позиции (без графиков).
2. Объясни по шагам, только числами из вывода:
   - спрос: `level` (средний месяц) и сезонный пик из `season_idx`; сколько месяцев дефицита исключено (`flags`);
   - запас: `stock` + `transit` (даты прихода, просрочки) → `stockout_date` / `cover_days`;
   - плечо `lead_days` и его источник `lead_src`; страховой `ss` и класс `abc`;
   - заказ: `orders[0]` — дата, приход, объём; формула: спрос на цикл после прихода + страховой − ожидаемый остаток − что ещё приедет, округление до кратности `pack`;
   - риски: `deficit` (сколько потеряем до прихода), `excess`.
3. Если пользователь не согласен с цифрой — найди, какой параметр её определяет (`config.toml` или данные), и предложи конкретное изменение + что оно сдвинет. Не правь число руками.
4. Ссылка на карточку в дашборде: `docs/index.html#sku=<SKU-ID>`.
